
# Embedded Systems Track

## Overview
This track is responsible for the hardware integration and embedded system implementation of Palm Pay.

## Responsibilities
- Raspberry Pi setup and configuration.
- Camera integration.
- Palm image acquisition.
- NIR camera integration.
- NIR illumination control.
- Communication with AI and backend components.
- Hardware testing and troubleshooting.

## Main Components
- Raspberry Pi
- RGB Camera
- NIR Camera
- NIR Illumination
- Image Acquisition
- Hardware Integration
