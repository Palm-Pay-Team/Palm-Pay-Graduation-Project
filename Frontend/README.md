
# Frontend Track

## Overview
This track is responsible for developing the user interface of the Palm Pay application.

## Responsibilities
- Develop application pages.
- Implement responsive interfaces.
- Connect frontend components with backend APIs.
- Display user information and transaction history.
- Build the merchant interface.
- Handle application navigation.

## Main Components
- User Dashboard
- Merchant Interface
- Authentication Pages
- Payment Interface
- Transaction History
